# DESIRE — интернет-магазин

Сайт: https://desire-shop.netlify.app

- `site/` — сам магазин (Netlify публикует эту папку автоматически при каждом изменении)
  - `data.js` — исходный каталог (40 моделей из каталога осень–зима 2026)
  - `config.js` — подключение к базе Supabase (только publishable key, секретный ключ сюда не класть)
  - `app.js` — логика: витрина, корзина, доставка Ozon/СДЭК, оплата по QR, панель сотрудников
- `db/supabase-setup.sql` — создание таблиц и правил доступа в Supabase (запускается один раз в SQL Editor)
