# DESIRE — интернет-магазин

Сайт: https://desire-store.ru · база: https://api.desire-store.ru (Supabase на своём сервере, Yandex Cloud, Россия)

- `site/` — сам магазин. Сервер забирает изменения из ветки main каждые 5 минут (`git pull` по cron) и раздаёт папку через Caddy с HTTPS.
  - `data.js` — исходный каталог (40 моделей из каталога осень–зима 2026)
  - `config.js` — адрес базы и publishable key (секретные ключи сюда не класть)
  - `app.js` — витрина, корзина, доставка Ozon/СДЭК, оплата по QR, статистика, панель сотрудников
- `db/supabase-setup.sql` — таблицы, функции и правила доступа (можно запускать повторно)
- `db/migrate-from-cloud.sh` — разовый перенос данных из облачного Supabase (выполнен 27.11.2026)

На сервере: `~/desire` — Caddy и копия репозитория, `~/supabase` — база (секреты в `~/supabase/.env`, в репозиторий не попадают).

_Изменения вносятся через Claude; сайт обновляется автоматически после каждой отправки в ветку main._
